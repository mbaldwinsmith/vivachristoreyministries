# Viva Cristo Rey Ministries

A lightweight static ministry website for Roisin Doherty, designed for GitHub Pages.

## Stack

- Semantic HTML
- Vanilla CSS
- Vanilla JavaScript
- No build step
- No framework or runtime dependency

## Local preview

Open `index.html` directly in a browser, or serve the folder with any simple static server.

## GitHub Pages

Publish from the `main` branch root in **Settings → Pages**.
